# 純 Google Apps Script 版部署方式

這個資料夾提供不用 Render 的版本。資料會直接寫入 Google 試算表，學生用 Apps Script Web App 網址進入遊戲。

## 建立方式

1. 建立一個 Google 試算表，命名為 `SDGs 綠色守護者 RPG`。
2. 在試算表選單點 `擴充功能` -> `Apps Script`。
3. 建立兩個檔案：`Code.gs` 與 `Index.html`。
4. 分別貼上本資料夾同名檔案的內容。
5. 點 `部署` -> `新增部署作業`，類型選 `網頁應用程式`。
6. `執行身分` 選 `我`，`誰可以存取` 選 `任何知道連結的使用者`。
7. 部署並授權後，複製 Web App 網址給學生使用。
